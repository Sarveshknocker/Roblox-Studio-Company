# Prompts for the owner

- **Start:** "Start the studio: let's make a Roblox game."
- **Status:** "Studio, give me a status report." / "What do you need me to decide?"
- **Steer:** "I want it scarier." · "Make it more social." · "Cut scope so we launch in 6 weeks."
- **Gate answers:** "Go with concept 2, but set it underwater." · "Approved for production." · "Not yet: fix the tutorial first."
- **Specific work:** "Balance the economy." · "Run a security review of the code." · "Plan a Halloween event."
- **Launch:** "Walk me through the launch checklist." (You publish, or approve the publish explicitly.)
